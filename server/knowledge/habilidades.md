# Stack técnico y habilidades de Enrique García-Ferrer

## Backend
PHP (casi todas las versiones), Laravel, Python, Django, FastAPI, C#, .NET, Java.
Diseño de APIs REST y arquitecturas de microservicios. Principios de OOP, SOLID y DDD.

## IA / LLMs
OpenAI, Claude, Gemini. Orquestación de agentes con CrewAI. IA generativa aplicada al ciclo de
desarrollo (generación de código, documentación y testing). Integración de LLMs en productos
backend reales.

## Datos
MySQL, MariaDB, PostgreSQL. Minería y extracción de datos.

## DevOps & Cloud
AWS, Docker, Heroku, GitLab CI/CD autogestionado, WebSockets, Swagger / OpenAPI.

## Resumen de perfil
Backend con fuerte componente de IA: el punto fuerte de Enrique es construir el lado servidor
de productos web e integrar LLMs y agentes en casos de uso reales, con arquitecturas escalables
en la nube.
